# Personal Ultra

Plataforma B2B2C para personal trainers entregarem uma consultoria digital premium aos alunos.

## Demo
- 1 app Expo com role switching: Trainer / Student.
- 2 APIs: Trainer API e Student API.
- 1 Domain, 1 Application, 1 Infrastructure e 1 PostgreSQL.

## Futuro
O mobile será separado em dois apps:
- `trainer-mobile`
- `student-mobile`

A demo deve ser modelada desde o início para esse split exigir extração, não reescrita.

> O personal prescreve. O aluno executa. A plataforma organiza. A IA explica.

A documentação de produto, arquitetura e milestones está em `docs/`.
