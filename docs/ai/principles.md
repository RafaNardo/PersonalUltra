# SVR AI Principles

1. The LLM does not own business decisions.
2. Method rules are the source of truth.
3. Engines return structured decisions.
4. Safety validation precedes mutations.
5. Important changes require confirmation.
6. Health ambiguity defaults to safety.
7. Every material decision must be explainable.
8. The LLM never writes directly to persistence.
9. Training/nutrition calculations belong to engines.
10. Present as **SVR Coach — baseado na metodologia SVR**.

## LLM must not
Create arbitrary workout prescriptions, calculate macros independently, modify calories directly, bypass restrictions, diagnose, prescribe treatment or mutate the DB directly.
